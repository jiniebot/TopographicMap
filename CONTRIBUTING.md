# Contributing

1. Discuss large or compatibility-breaking changes first.
2. Never commit game assets, credentials, generated output, or machine-specific files.
3. Run `npm install`, `npm run check`, and the relevant preflight/preview command.
4. Document new commands, dependencies, environment variables, and formats.
5. For visual changes, identify the tested map and zoom range and include screenshots.

Contributors must have the right to submit their code and data. Contribution licensing remains pending until the repository owner selects a project license.
